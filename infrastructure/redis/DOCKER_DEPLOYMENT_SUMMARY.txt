 USO RÁPIDO
================================================================================

OPCIÓN 1 - Script standalone (solo Redis):
  cd infrastructure/redis/dev/
  ./build_and_run_docker.sh build
  ./build_and_run_docker.sh run

OPCIÓN 2 - Docker Compose (stack completo):
  cd infrastructure/servers/frontend/
  cp .env.example .env
  nano .env  # Ajustar ENVIRONMENT=dev
  docker-compose up -d
