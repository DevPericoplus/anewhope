# Documentación

## Recursos técnicos

Consulta la documentación del ecosistema LAIM para configurar entornos, desplegar servicios y operar modelos de IA local.

### Guías principales

1. **Arquitectura** — Flujo LAIM Web → Middleware → Broker → Backend Core
2. **Base de datos** — Esquema `laim_core_db` y credenciales por entorno
3. **Entrenamientos** — Plantillas de jobs, estados y encadenamiento padre-hijo
4. **Seguridad** — Autenticación JWT, sesiones Redis y permisos

### Referencia rápida

```bash
# Arrancar LAIM Web en macbook
cd src/apps/9_laimweb
./run.sh
```
