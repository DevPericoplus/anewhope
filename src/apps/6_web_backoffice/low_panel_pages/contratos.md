# Contratos

## Acuerdos Contractuales

Información sobre los diferentes tipos de contratos disponibles.

### Tipos de Contratos

#### Contrato de Servicios Estándar

- Duración: Mensual o anual
- Renovación automática
- Cancelación con 30 días de antelación

#### Contrato Enterprise

- Duración personalizada
- SLA garantizado
- Condiciones negociadas
- Facturación personalizada

#### Acuerdo de Procesamiento de Datos (DPA)

Requerido para el cumplimiento de GDPR:

- Define responsabilidades sobre los datos
- Medidas de seguridad acordadas
- Procedimientos ante incidencias
- Auditorías permitidas

### Documentos Disponibles

1. **Contrato Marco de Servicios**: Términos generales del servicio
2. **DPA (Data Processing Agreement)**: Acuerdo de procesamiento de datos
3. **SLA (Service Level Agreement)**: Niveles de servicio garantizados
4. **NDA (Non-Disclosure Agreement)**: Acuerdo de confidencialidad
