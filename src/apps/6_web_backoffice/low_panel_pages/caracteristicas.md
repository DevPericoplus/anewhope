# Características

## Plataforma de Personalización de Modelos LLM

Myllm ofrece una plataforma completa para la personalización y entrenamiento de modelos de lenguaje.

### Tecnologías


| **Tecnología** | **Tipo de Estructura** | **Caso de Uso Ideal** |
| --- | --- | --- |
| **Fine-tuning** | **Interna (Pesos del modelo)** | Especializar el lenguaje en un dominio (médico, legal), ajustar el tono de voz o aprender formatos de salida muy específicos. |
| **RAG (Tradicional)** | **Externa (Vectores/Texto)** | Consultar bases de conocimiento que cambian rápido (noticias, manuales técnicos) y reducir alucinaciones citando fuentes. |
| **GraphRAG** | Relacional / Jerárquica | Análisis de leyes, trazabilidad de procesos y conexión entre entidades en redes complejas. |
| **Agentes** | Multifuente / Metadatos | Consultas complejas que requieren lógica y acceso a distintas herramientas (SQL, APIs, PDFs). |
| **Contexto Largo** | Documental masiva | Auditoría de proyectos completos o análisis profundo de libros donde el orden y la coherencia global son clave. |
| **DSPy** | Programática | Optimización de flujos de trabajo donde se necesita que la IA aprenda a usar los documentos por sí misma mediante lógica de programación. |
| **Creación de agentes MCP** | Interoperabilidad / Extensible | Integración de modelos con herramientas externas (IDEs, bases de datos, APIs) mediante protocolo estandarizado, permitiendo acceso a contexto dinámico y ejecución de acciones en sistemas externos. |

### Principales Características

- **Gestión de Proyectos**: Organiza tus proyectos de IA con control de versiones y seguimiento de progreso.
- **Interfaz Intuitiva**: Panel de control diseñado para facilitar la gestión de entrenamientos.
- **Seguridad Empresarial**: Protección de datos con encriptación de extremo a extremo.

### Beneficios

1. Reducción del tiempo de desarrollo
2. Mayor precisión en respuestas específicas del dominio
3. Control total sobre los datos de entrenamiento
4. Soporte técnico especializado
